Automated quality control of droplet-based single-cell and single-nucleus RNA-seq data.

`validrops` is a Python/scanpy port of the R package
[valiDrops](https://doi.org/10.1093/nargab/lqad101) (Kavaliauskaite & Madsen,
2023): it ranks barcodes, filters on quality metrics, filters on expression-based
cluster metrics, and optionally labels dead cells — emitting an in-place
annotated `AnnData` rather than a new object.

## Pipeline

| Stage | Module | What it does |
|---|---|---|
| 1. Barcode ranking | `validrops.pp.rank_barcodes` | Rank barcodes by UMI/gene count and detect the knee separating cells from ambient droplets |
| 2a. Quality metrics | `validrops.tl.quality_metrics` | Per-barcode mito/ribo/coding fractions, log UMIs/features |
| 2b. Quality filtering | `validrops.pp.quality_filter` | Mito-fraction cap, feature↔UMI residual band, coding-fraction band |
| 3a. Expression metrics | `validrops.tl.expression_metrics` | HVG selection, SVD embedding, SNN + Louvain clustering, per-cluster marker stats |
| 3b. Expression filtering | `validrops.pp.expression_filter` | Drop clusters without coherent marker expression |
| 4. Dead-cell labelling | `validrops.pp.label_dead` | Heuristic dead score + consensus ridge-training loop (off by default) |

## Installation

You need Python 3.11 or newer. We recommend installing [uv][]:

```bash
uv sync                                    # install dependencies into a project venv
uv sync --group test --group dev           # add test + dev tools
```

## Usage

```python
import scanpy as sc
import validrops

adata = sc.read_10x_h5("raw_feature_bc_matrix.h5")
adata.var_names_make_unique()

validrops.validrops(adata)          # annotates in place

clean = adata[adata.obs["qc_pass"]].copy()
```

The object is **annotated in place** — nothing is removed from `adata`. The QC
verdict lands in `adata.obs["qc_pass"]`, per-stage diagnostics in `adata.obs`
(e.g. `rank_pass`, `pass_mito`, `cluster`) and `adata.uns["validrops"]`
(thresholds, gene sets, params). Subset afterwards with
`adata[adata.obs["qc_pass"]].copy()`.

For very large datasets run `validrops.validrops(adata)` as-is first; the
`label_dead` stage (slow, stochastic) is off by default.

Diagnostic plots are available in `validrops.pl`: `barcode_rank`,
`mito_threshold`, `umi_vs_features`, `coding_fraction`, `dead_score`.

## Package layout (scverse conventions)

```
src/validrops/
  validrops()        end-to-end orchestrator (validrops/__init__.py -> _pipeline.py)
  pp/                preprocessing — filters and labels barcodes (rank_barcodes,
                     quality_filter, expression_filter, label_dead)
  tl/                tools — metrics and numerical primitives (quality_metrics,
                     expression_metrics, _stats/_uik/_segmented/_deviance/
                     _wilcox/_snn/_ridge/_annotation)
  pl/                plotting — the five QC diagnostic plots
  data/              annotation.parquet (6-species gene table, from valiDrops sysdata.rda)
```

All public functions take an `AnnData` as first argument, modify it **inplace**,
and return `None`.

## Validation against R

Measured against R-generated fixtures on PBMC 4K (`tests/reference_outputs/`,
regenerated by `tests/R/generate_reference.R`):

| Stage | Metric | Value |
|---|---|---|
| Stage 1 `rank_barcodes` | barcode concordance | 1.0000 |
| Stage 2b `quality_filter` | barcode concordance | 1.0000 |
| Stage 2a metrics | Pearson r | > 0.99 |
| Stage 3a embedding | per-PC \|r\| vs irlba | ~1.0 |
| Stage 3a variable features | set overlap vs R | 100% |
| Stage 3a deep clustering | ARI vs Seurat | ~0.74–0.86 (structural ceiling, see below) |
| Stage 3b `expression_filter` | barcode concordance (R inputs) | exact; end-to-end 0.9261 |
| Stage 4a dead score | rtol | 1e-10 |
| Stage 4a soft labels | exact match | yes (107-dead split) |
| Stage 4b dead count | band vs R (71) | stable ~34–45 |
| **End-to-end pipeline** | **barcode concordance** | **0.9193** (bounded > 0.90) |

### Known structural ceilings (not port errors)

The end-to-end gap is fully localised to stage 3b's deep clustering, and its
cause is **Louvain implementation divergence**, not anything upstream:

- Feeding R's own SNN graph (built by Seurat 5.4's annoy backend, exactly as
  the reference generator did) into our igraph `community_multilevel` still caps
  at ARI ~0.83–0.86 across every resolution and seed. igraph's Louvain ≠
  Seurat's C++ `RunModularityClustering` local-search tie-breaking at high
  resolution (84 tiny clusters, min-size == 5 target). Only a faithful port of
  Seurat's whole C++ Louvain could close the last ~5%.
- `pct.1`/`pct.2` correlate at ~0.97/0.99 because the R reference regenerates
  the shallow clustering after the RNG is consumed, so the stored stats' `rest`
  sets are not exactly reproducible.
- Stage-4b dead count lands in a stable ~34–45 band vs R's 71: glmnet's
  `lambda.1se` path vs sklearn's ridge grid, and pROC vs sklearn ROC semantics.

- `uv sync --group test` installs the test group (scanpy lives there, not in the
  base dependencies). `uv add/remove` prunes non-default dependency groups —
  re-sync with `--group test` after adding/removing anything.

```bash
Rscript tests/R/extract_annotation.R   # sysdata.rda -> src/validrops/data/annotation.parquet

```

- `tests/data/pbmc4k/raw.h5` is gitignored (17 MB); the suite skips tests that
  need it when it is absent.

### R → Python translation rules

- AnnData is **cells × genes** (R's matrix is genes × cells — transpose all indexing)
- All R 1-based indexing → Python 0-based (audit every slice/`which()` call)
- R `var()` uses the `n-1` denominator → use `ddof=1` with numpy
- R `dgCMatrix` is CSC → be explicit with `scipy.sparse` format
- R recycles shorter vectors → numpy broadcasts differently; verify arithmetic
- Random seeds differ between R and Python → validate statistical equivalence,
  not bit-for-bit
- Accumulate every count summation in float64
  (`X.sum(axis=..., dtype=np.float64)`) — `read_10x_h5` returns float32 and
  bare sums drift ~1e-7 against R's doubles

### R → Python dependency map

All R algorithms are ported in-repo; nothing delegates to scanpy for them.

| R | Python |
|---|--------|
| `segmented` | custom impl in `tl/_segmented.py` (Muggeo, damped-step + line-search) |
| `mixtools::normalmixEM` | `sklearn.mixture.GaussianMixture` (`init_params="random"`, not kmeans) |
| `inflection` | custom impl in `tl/_uik.py` (unit-invariant knee) |
| `robustbase::Sn` | custom impl in `tl/_stats.py` |
| `scry` (deviance HVGs) | custom impl in `tl/_deviance.py` |
| `irlba` | `scipy.sparse.linalg.svds` |
| Seurat SNN + Louvain | custom impl in `tl/_snn.py` (exact kNN + igraph `community_multilevel`) |
| `presto::wilcoxauc` | custom vectorised impl in `tl/_wilcox.py` |
| `glmnet` (binomial `lambda.1se`) | L2 `LogisticRegression` path + manual 1se rule in `tl/_ridge.py` (not `RidgeCV`) |
| `pROC::coords(roc, "best")` | `tl/_ridge.py::roc_best_threshold` |
| `BiocParallel` | `joblib.Parallel` |
| `Matrix` | `scipy.sparse` |
| `DropletUtils` I/O | `scanpy.read_10x_mtx` / `scanpy.read_10x_h5` |

### R quirks preserved verbatim (do not "fix")

1. `expression_filter.R:77` — `-log10(0) = Inf`, so clusters with `min_fdr == 0`
   survive any finite significance bar; numpy's divide warning is silenced to
   match R's silence.
2. `expression_metrics.R:172` — `1:min(n_de, top_n)` collapses to the single
   most significant gene when `n_de == 0` (R's `1:0` is `c(1, 0)`).
3. `label_dead.R:163-179` — stage 4 scales **per cell** where stage 3 scales per
   gene; both genuinely differ and both are reproduced. The `var.feats`
   computed at `R:166-167` is never used; the SVD runs on all non-zero genes.
4. `label_dead.R:225-236, 276-277` — the initial score/QC weight vector is dead
   code; only the per-replicate weights that reach the model are computed.

Key constants are transcribed from the R source into `src/validrops/_constants.py`
— do not change them without a matching R change.
